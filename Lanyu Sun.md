# Git Learning Notes

## 1. Version Control

Version control tracks changes to files over time. It helps developers review previous versions and collaborate on projects.

## 2. Basic Git Commands

- `git init`: Initialise a Git repository.
- `git status`: Check the current state of the repository.
- `git add`: Stage changes for a commit.
- `git commit`: Save staged changes in the local repository.
- `git log`: View commit history.
- `git push`: Upload local commits to a remote repository.
- `git pull`: Fetch and integrate changes from a remote repository.

## 3. GitHub Collaboration

- **Fork**: Create a copy of another user's repository under your account.
- **Clone**: Copy a repository to your local computer.
- **Pull Request (PR)**: Propose changes and ask for them to be merged into another repository.

## 4. Diff and Patch

- **Diff**: Shows the differences between files.
- **Patch**: Applies a set of changes to a file.

## 5. Open-Source Licences

- **MIT**: A permissive open-source licence.
- **GPL**: A copyleft licence with source-sharing requirements when distributing covered works.
- **LGPL**: A licence commonly used for software libraries.
- **Apache 2.0**: A permissive licence with explicit patent provisions.
